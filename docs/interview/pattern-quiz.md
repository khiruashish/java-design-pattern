# Name That Pattern

A quick way to test yourself before an interview. Each question plays one of the handbook's animated walkthroughs with the names hidden: the boxes are just **A**, **B**, **C**. Watch what moves between them, then pick the pattern.

- **Scoring:** 2 points for a right answer, 1 if you used **Show the names** first.
- **Hard mode** hides the labels on the moving messages too, so you have only the shape of the conversation to go on.
- **Filter** by family (Creational, Structural, Behavioral, Concurrency, Microservices, Architecture) to drill one area.
- If you mix up a known look-alike pair, the answer explains how to tell them apart.

!!! tip "Use it like an interviewer would"
    Before you click an answer, say out loud what you see: who calls whom, what gets created, what is shared, what happens on failure. Interviewers grade that reasoning as much as the name.
