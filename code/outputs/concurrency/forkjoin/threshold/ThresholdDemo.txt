=== Challenge: Choosing a Fork/Join Threshold (10,000,000 elements) ===
threshold          1 -> 19,999,999 tasks created, result 5,000,000
threshold      1,000 ->     32,767 tasks created, result 5,000,000
threshold    100,000 ->        255 tasks created, result 5,000,000
threshold 10,000,000 ->          1 tasks created, result 5,000,000
Too small: millions of tiny tasks (overhead dominates). Too big: one task, no parallelism.
