    Capstone: FreshCart Grocery Platform¶

    🔴 Advanced Capstone

    TL;DR

    FreshCart is a small but complete grocery platform (catalog, cart, pricing, checkout, inventory, payments, delivery slots, orders, notifications, loyalty) built as a modular monolith in plain Java 21, with a real H2 database for orders and the outbox. It combines 22 patterns from this handbook in one runnable program, and shows each one doing a real job, including failure scenarios: declined payments, a provider outage, duplicate taps, a crashing relay and a misbehaving script.

    Run it: cd code && ./run-demos.sh, then read code/outputs/capstone/FreshCartDemo.txt, or run com.handbook.capstone.FreshCartDemo from your IDE.

    1. Requirements¶

    Functional

    • Browse products (fast, cached); categories carry GST rates.
    • Cart with add/remove and undo.
    • Coupons: "10% off fruit (max ₹100)", "₹75 off above ₹1,000"; free delivery above ₹500.
    • Checkout: validate, reserve stock, book a delivery slot, take payment (UPI via a third-party provider, or cash on delivery), create the order.
    • Order lifecycle: confirmed → packed → out for delivery → delivered (cancel only before dispatch).
    • SMS on every order change; loyalty points (1 per ₹100); "My orders" screen; low-stock alerts for the ops team.

    Non-functional

    • A double tap on "Pay" never creates two orders or two charges.
    • A failed checkout never leaves stock reserved, slots booked or money taken.
    • A payment provider outage must not hang checkouts; customers can still pay by COD.
    • Events are never lost when the database commit succeeds, and duplicates have no effect.
    • Scripts and bots can't hammer checkout.

    2. Architecture¶

    FreshCart is a modular monolith: one deployable, with modules that talk through small APIs and in-process events, and could later be extracted into microservices.

    package com.handbook.capstone;

import com.handbook.capstone.cart.Cart;
import com.handbook.capstone.checkout.CheckoutChecks;
import com.handbook.capstone.delivery.DeliveryService;
import com.handbook.capstone.inventory.InventoryService;
import com.handbook.capstone.ordering.CheckoutSaga;
import com.handbook.capstone.ordering.OrderState;
import com.handbook.capstone.ordering.OrderStore;
import com.handbook.capstone.ordering.OrderStore.OrderRow;
import com.handbook.capstone.ordering.TokenBucket;
import com.handbook.capstone.payment.Payments;
import com.handbook.capstone.pricing.Pricing;
import com.handbook.capstone.shared.DomainEvents;
import com.handbook.capstone.shared.Ids;

import java.util.List;
import java.util.Optional;
import java.util.function.Consumer;

/**
 * [Facade] The single entry point the app's API layer calls. It hides eight modules and the order
 * in which they must be used behind three methods: checkout, advance, relayEvents.
 */
public final class FreshCart {

    public record CheckoutResult(int status, String orderId, String message) {
        @Override
        public String toString() {
            return status + " " + (orderId == null ? "" : orderId + " ") + message;
        }
    }

    private final Pricing pricing;
    private final CheckoutChecks checks;
    private final InventoryService inventory;
    private final DeliveryService delivery;
    private final DeliveryService.SlotStrategy slotStrategy;
    private final Payments.GatewayFactory payments;
    private final OrderStore store;
    private final TokenBucket limiter;
    private final DomainEvents events;
    private final CheckoutSaga saga;

    public FreshCart(Pricing pricing, CheckoutChecks checks, InventoryService inventory, DeliveryService delivery,
                     DeliveryService.SlotStrategy slotStrategy, Payments.GatewayFactory payments, OrderStore store,
                     TokenBucket limiter, DomainEvents events, Consumer<String> sagaLog) {
        this.pricing = pricing;
        this.checks = checks;
        this.inventory = inventory;
        this.delivery = delivery;
        this.slotStrategy = slotStrategy;
        this.payments = payments;
        this.store = store;
        this.limiter = limiter;
        this.events = events;
        this.saga = new CheckoutSaga(sagaLog);
    }

    public CheckoutResult checkout(Cart cart, String pincode, String coupon, String paymentMethod, String idempotencyKey) {
        Optional<OrderRow> existing = store.byIdempotencyKey(idempotencyKey); // (1)!
        if (existing.isPresent()) {
            return new CheckoutResult(200, existing.get().id(), "already placed (idempotent replay), no new charge");
        }
        if (!limiter.tryAcquire(cart.customerId())) { // (2)!
            return new CheckoutResult(429, null, "too many checkout attempts, try again in a minute");
        }
        Optional<String> problem = checks.check(new CheckoutChecks.Request(cart, pincode)); // (3)!
        if (problem.isPresent()) {
            return new CheckoutResult(422, null, problem.get());
        }
        Pricing.Breakdown price = pricing.price(cart, coupon);
        String orderId = Ids.INSTANCE.next("ORD");
        Payments.PaymentGateway gateway = payments.forMethod(paymentMethod); // (4)!
        DeliveryService.Slot[] slot = new DeliveryService.Slot[1];
        try {
            saga.run(List.of( // (5)!
                    new CheckoutSaga.Step("reserve stock", () -> inventory.reserve(cart), () -> inventory.release(cart)),
                    new CheckoutSaga.Step("book delivery slot", () -> slot[0] = delivery.book(slotStrategy),
                            () -> delivery.cancel(slot[0])),
                    new CheckoutSaga.Step("charge " + price.total() + " via " + paymentMethod, () -> {
                        Payments.Result r = gateway.charge(new Payments.Charge(orderId, cart.customerId(), price.total()));
                        if (!(r instanceof Payments.Paid)) {
                            throw new IllegalStateException(r.toString());
                        }
                    }, () -> gateway.refund(orderId)),
                    new CheckoutSaga.Step("save order + outbox event", () -> store.insert( // (6)!
                            new OrderRow(orderId, cart.customerId(), price.total(), OrderState.CONFIRMED, idempotencyKey),
                            Ids.INSTANCE.next("EVT")), () -> { })));
        } catch (CheckoutSaga.Failed f) {
            return new CheckoutResult(402, null, "checkout failed: " + f.getMessage());
        }
        return new CheckoutResult(201, orderId, price.total() + ", delivery at " + slot[0].start());
    }

    /** Moves an order through its lifecycle; the state object decides what's legal. */
    public String advance(String orderId, String action) {
        OrderRow order = store.byId(orderId).orElseThrow();
        try {
            OrderState next = order.state().on(action); // (7)!
            store.updateState(order, next, Ids.INSTANCE.next("EVT"));
            return orderId + " " + order.state() + " -> " + next;
        } catch (IllegalStateException e) {
            return orderId + " rejected: " + e.getMessage();
        }
    }

    /** Runs the outbox relay once (a scheduler does this every few hundred ms in production). */
    public int relayEvents() {
        return store.relay(events);
    }
}
    1. Idempotency first: a retried request with the same key returns the original order, without charging again.
    2. Rate limiting before any expensive work.
    3. The validation chain rejects bad requests with a reason (422).
    4. The factory picks the gateway; the checkout doesn't know PayFast exists.
    5. The saga: each step has a compensation. Payment is the pivot; saving the order is the last, local step.
    6. The order and its OrderPlaced event are written in one database transaction (outbox).
    7. The state object decides whether the action is legal.

/** [Builder] Products have many optional attributes; the builder validates them together. */
public record Product(String sku, String name, Category category, Money price, int maxPerOrder, boolean organic) {

    public static Builder builder(String sku) {
        return new Builder(sku);
    }

    public static final class Builder {
        private final String sku;
        private String name;
        private Category category;
        private Money price;
        private int maxPerOrder = 10;
        private boolean organic;

        private Builder(String sku) {
            this.sku = sku;
        }

        public Builder name(String name) {
            this.name = name;
            return this;
        }

        public Builder category(Category category) {
            this.category = category;
            return this;
        }

        public Builder price(Money price) {
            this.price = price;
            return this;
        }

        public Builder maxPerOrder(int max) {
            this.maxPerOrder = max;
            return this;
        }

        public Builder organic() {
            this.organic = true;
            return this;
        }

        public Product build() {
            if (name == null || category == null || price == null || price.paise() <= 0) {
                throw new IllegalStateException(sku + ": name, category and a positive price are required");
            }
            return new Product(sku, name, category, price, maxPerOrder, organic);
        }
    }
}

/**
 * [Flyweight] Thousands of products share a handful of category objects (name, tax rate, whether
 * it's perishable). Instances are cached and immutable; products only hold a reference.
 */
public final class Category {

    private static final Map<String, Category> CACHE = new ConcurrentHashMap<>();

    private final String name;
    private final int gstPercent;
    private final boolean perishable;

    private Category(String name, int gstPercent, boolean perishable) {
        this.name = name;
        this.gstPercent = gstPercent;
        this.perishable = perishable;
    }

    public static Category of(String name, int gstPercent, boolean perishable) {
        return CACHE.computeIfAbsent(name, n -> new Category(n, gstPercent, perishable));
    }

    public static int cachedInstances() {
        return CACHE.size();
    }

    public String name() {
        return name;
    }

    public int gstPercent() {
        return gstPercent;
    }

    public boolean perishable() {
        return perishable;
    }

    @Override
    public String toString() {
        return name;
    }
}

    package com.handbook.capstone.catalog;

import java.util.Map;
import java.util.Optional;
import java.util.concurrent.ConcurrentHashMap;

/** The catalog module's public API (a port), with the real store and a caching proxy. */
public interface Catalog {

    Optional<Product> find(String sku);

    /** The "database" (slow in real life). */
    final class InMemoryCatalog implements Catalog {
        private final Map<String, Product> products = new ConcurrentHashMap<>();
        int reads;

        public InMemoryCatalog add(Product p) {
            products.put(p.sku(), p);
            return this;
        }

        @Override
        public Optional<Product> find(String sku) {
            reads++;
            return Optional.ofNullable(products.get(sku));
        }

        public int reads() {
            return reads;
        }
    }

    /** [Proxy] Same interface, adds caching; callers can't tell the difference. */
    final class CachingCatalog implements Catalog {
        private final Catalog target;
        private final Map<String, Optional<Product>> cache = new ConcurrentHashMap<>();

        public CachingCatalog(Catalog target) {
            this.target = target;
        }

        @Override
        public Optional<Product> find(String sku) {
            return cache.computeIfAbsent(sku, target::find);
        }
    }
}

    package com.handbook.capstone.cart;

import com.handbook.capstone.catalog.Product;
import com.handbook.capstone.shared.Money;

import java.util.ArrayDeque;
import java.util.Collections;
import java.util.Deque;
import java.util.LinkedHashMap;
import java.util.Map;

/**
 * [Command] Every change to the cart is a command object that knows how to undo itself, so the app
 * can offer "Undo" after an accidental removal.
 */
public final class Cart {

    public interface CartCommand {
        void execute(Cart cart);

        void undo(Cart cart);

        String describe();
    }

    public record AddItem(Product product, int qty) implements CartCommand {
        @Override
        public void execute(Cart cart) {
            cart.lines.merge(product.sku(), new Line(product, qty), (a, b) -> new Line(a.product(), a.qty() + b.qty()));
        }

        @Override
        public void undo(Cart cart) {
            cart.change(product, -qty);
        }

        @Override
        public String describe() {
            return "add " + qty + " x " + product.name();
        }
    }

    public record RemoveItem(Product product, int qty) implements CartCommand {
        @Override
        public void execute(Cart cart) {
            cart.change(product, -qty);
        }

        @Override
        public void undo(Cart cart) {
            new AddItem(product, qty).execute(cart);
        }

        @Override
        public String describe() {
            return "remove " + qty + " x " + product.name();
        }
    }

    public record Line(Product product, int qty) {
        public Money total() {
            return product.price().times(qty);
        }
    }

    private final String customerId;
    private final Map<String, Line> lines = new LinkedHashMap<>();
    private final Deque<CartCommand> history = new ArrayDeque<>();

    public Cart(String customerId) {
        this.customerId = customerId;
    }

    public void apply(CartCommand command) {
        command.execute(this);
        history.push(command);
    }

    public String undo() {
        if (history.isEmpty()) {
            return "nothing to undo";
        }
        CartCommand last = history.pop();
        last.undo(this);
        return "undid: " + last.describe();
    }

    private void change(Product p, int delta) {
        lines.computeIfPresent(p.sku(), (k, l) -> l.qty() + delta <= 0 ? null : new Line(p, l.qty() + delta));
    }

    public Map<String, Line> lines() {
        return Collections.unmodifiableMap(lines);
    }

    public Iterable<Line> orderedLines() {
        return lines.values();
    }

    public String customerId() {
        return customerId;
    }

    public Money subtotal() {
        return lines.values().stream().map(Line::total).reduce(Money.ZERO, Money::plus);
    }

    public int itemCount() {
        return lines.values().stream().mapToInt(Line::qty).sum();
    }

    @Override
    public String toString() {
        StringBuilder sb = new StringBuilder();
        lines.values().forEach(l -> sb.append(l.qty()).append(" x ").append(l.product().name()).append("; "));
        return sb.isEmpty() ? "(empty)" : sb.substring(0, sb.length() - 2);
    }
}

    package com.handbook.capstone.pricing;

import com.handbook.capstone.cart.Cart;
import com.handbook.capstone.shared.Money;

import java.util.ArrayList;
import java.util.List;
import java.util.function.Function;
import java.util.function.Predicate;

/**
 * [Specification] decides whether a promotion applies; [Strategy] decides how much it's worth.
 * Promotions are data: marketing adds new ones without changing the engine.
 */
public final class Pricing {

    public record Promotion(String code, Predicate<Cart> eligible, Function<Cart, Money> discount) {
    }

    public record Breakdown(Money subtotal, List<String> applied, Money discount, Money gst, Money deliveryFee, Money total) {
        @Override
        public String toString() {
            return "subtotal " + subtotal + " - discount " + discount + " " + applied + " + GST " + gst
                    + " + delivery " + deliveryFee + " = " + total;
        }
    }

    /** Specifications. */
    public static Predicate<Cart> minSubtotal(Money min) {
        return c -> c.subtotal().compareTo(min) >= 0;
    }

    public static Predicate<Cart> containsCategory(String category) {
        return c -> c.lines().values().stream().anyMatch(l -> l.product().category().name().equals(category));
    }

    /** Strategies. */
    public static Function<Cart, Money> percentOffCategory(String category, int pct, Money cap) {
        return c -> {
            Money base = c.lines().values().stream().filter(l -> l.product().category().name().equals(category))
                    .map(Cart.Line::total).reduce(Money.ZERO, Money::plus);
            Money d = base.percent(pct);
            return d.compareTo(cap) > 0 ? cap : d;
        };
    }

    public static Function<Cart, Money> flat(Money amount) {
        return c -> amount;
    }

    private final List<Promotion> promotions = new ArrayList<>();
    private final Money freeDeliveryAbove;
    private final Money deliveryFee;

    public Pricing(Money freeDeliveryAbove, Money deliveryFee) {
        this.freeDeliveryAbove = freeDeliveryAbove;
        this.deliveryFee = deliveryFee;
    }

    public Pricing add(Promotion p) {
        promotions.add(p);
        return this;
    }

    public Breakdown price(Cart cart, String couponCode) {
        Money subtotal = cart.subtotal();
        List<String> applied = new ArrayList<>();
        Money discount = Money.ZERO;
        for (Promotion p : promotions) {
            if (p.code().equalsIgnoreCase(couponCode) && p.eligible().test(cart)) {
                discount = discount.plus(p.discount().apply(cart));
                applied.add(p.code());
            }
        }
        Money gst = Money.ZERO;
        for (Cart.Line l : cart.orderedLines()) {
            gst = gst.plus(l.total().percent(l.product().category().gstPercent()));
        }
        Money afterDiscount = subtotal.minus(discount);
        Money delivery = afterDiscount.compareTo(freeDeliveryAbove) >= 0 ? Money.ZERO : deliveryFee;
        return new Breakdown(subtotal, applied, discount, gst, delivery, afterDiscount.plus(gst).plus(delivery));
    }
}

    package com.handbook.capstone.checkout;

import com.handbook.capstone.cart.Cart;

import java.util.Optional;
import java.util.Set;
import java.util.function.Predicate;

/**
 * [Chain of Responsibility] Pre-checkout validations as a chain: each link either rejects the
 * request with a reason or passes it on. New checks are new links.
 */
public abstract class CheckoutChecks {

    public record Request(Cart cart, String pincode) {
    }

    private CheckoutChecks next;

    public CheckoutChecks then(CheckoutChecks next) {
        this.next = next;
        return next;
    }

    public final Optional<String> check(Request r) {
        Optional<String> problem = inspect(r);
        if (problem.isPresent() || next == null) {
            return problem;
        }
        return next.check(r);
    }

    protected abstract Optional<String> inspect(Request r);

    public static CheckoutChecks of(Predicate<Request> ok, String reason) {
        return new CheckoutChecks() {
            @Override
            protected Optional<String> inspect(Request r) {
                return ok.test(r) ? Optional.empty() : Optional.of(reason);
            }
        };
    }

    public static CheckoutChecks standardChain(Set<String> servedPincodes) {
        CheckoutChecks head = of(r -> r.cart().itemCount() > 0, "cart is empty");
        head.then(of(r -> r.cart().lines().values().stream().allMatch(l -> l.qty() <= l.product().maxPerOrder()),
                        "per-product limit exceeded"))
                .then(of(r -> servedPincodes.contains(r.pincode()), "we don't deliver to this pincode yet"));
        return head;
    }
}

    package com.handbook.capstone.inventory;

import com.handbook.capstone.cart.Cart;
import com.handbook.capstone.shared.DomainEvents;
import com.handbook.capstone.shared.Ids;

import java.util.LinkedHashMap;
import java.util.Map;

/** Inventory module: reservations with release (used as a saga step and its compensation). */
public final class InventoryService {

    private final Map<String, Integer> stock = new LinkedHashMap<>();
    private final DomainEvents events;
    private final int lowStockThreshold;

    public InventoryService(DomainEvents events, int lowStockThreshold) {
        this.events = events;
        this.lowStockThreshold = lowStockThreshold;
    }

    public InventoryService stock(String sku, int qty) {
        stock.put(sku, qty);
        return this;
    }

    public synchronized void reserve(Cart cart) {
        for (Cart.Line l : cart.orderedLines()) { // check everything first: all-or-nothing
            if (stock.getOrDefault(l.product().sku(), 0) < l.qty()) {
                throw new IllegalStateException("only " + stock.getOrDefault(l.product().sku(), 0) + " " + l.product().name() + " left");
            }
        }
        for (Cart.Line l : cart.orderedLines()) {
            int left = stock.merge(l.product().sku(), -l.qty(), Integer::sum);
            if (left <= lowStockThreshold) {
                events.publish(new DomainEvents.StockLow(Ids.INSTANCE.next("EVT"), l.product().sku(), left));
            }
        }
    }

    public synchronized void release(Cart cart) {

/** Payment module: a port, an adapter for an external provider, a factory, and a circuit breaker. */
public final class Payments {

    private Payments() {
    }

    public record Charge(String reference, String customerId, Money amount) {
    }

    public sealed interface Result permits Paid, Declined, Unavailable {
    }

    public record Paid(String transactionId) implements Result {
    }

    public record Declined(String reason) implements Result {
    }

    public record Unavailable(String reason) implements Result {
    }

    /** The port the checkout depends on. */
    public interface PaymentGateway {
        Result charge(Charge charge);

        void refund(String reference);
    }

    /** A third-party SDK with its own vocabulary (we can't change it). */
    public interface PayFastSdk {
        Map<String, String> createPayment(String merchantKey, String amountRupees, String orderRef);

        void reverse(String orderRef);
    }

    /** [Adapter] Translates our port into PayFast's API and its status codes back into our Result. */
    public static final class PayFastAdapter implements PaymentGateway {
        private final PayFastSdk sdk;

        public PayFastAdapter(PayFastSdk sdk) {
            this.sdk = sdk;
        }

        @Override
        public Result charge(Charge c) {
            Map<String, String> r = sdk.createPayment("MK-FRESHCART",
                    String.format("%d.%02d", c.amount().paise() / 100, c.amount().paise() % 100), c.reference());
            return switch (r.get("status")) {
                case "CAPTURED" -> new Paid(r.get("txn"));
                case "DECLINED" -> new Declined(r.get("reason"));
                default -> new Unavailable("unexpected PayFast status " + r.get("status"));
            };
        }

        @Override
        public void refund(String reference) {
            sdk.reverse(reference);
        }
    }

    /** Cash on delivery: always "succeeds" now; money is collected at the door. */
    public static final class CashOnDelivery implements PaymentGateway {
        @Override
        public Result charge(Charge c) {
            return new Paid("COD-" + c.reference());
        }

        @Override
        public void refund(String reference) {
        }
    }

    /**
     * [Decorator] + [Circuit Breaker]: wraps any gateway. After N consecutive failures it stops
     * calling the provider for a cool-down period and fails fast.
     */
    public static final class CircuitBreakerGateway implements PaymentGateway {
        private final PaymentGateway inner;
        private final int threshold;
        private final Duration openFor;
        private final Clock clock;
        private int consecutiveFailures;
        private Instant openedAt;

        public CircuitBreakerGateway(PaymentGateway inner, int threshold, Duration openFor, Clock clock) {
            this.inner = inner;
            this.threshold = threshold;
            this.openFor = openFor;
            this.clock = clock;
        }

        @Override
        public synchronized Result charge(Charge c) {
            if (openedAt != null && clock.instant().isBefore(openedAt.plus(openFor))) {
                return new Unavailable("payment circuit OPEN, failing fast");
            }
            Result r;
            try {
                r = inner.charge(c);
            } catch (RuntimeException e) {
                r = new Unavailable(e.getMessage());
            }
            if (r instanceof Unavailable) {
                if (++consecutiveFailures >= threshold) {
                    openedAt = clock.instant();
                }
            } else {
                consecutiveFailures = 0;
                openedAt = null;
            }
            return r;
        }

        @Override
        public void refund(String reference) {
            inner.refund(reference);
        }

        public synchronized boolean isOpen() {
            return openedAt != null && clock.instant().isBefore(openedAt.plus(openFor));
        }
    }

    /** [Factory Method] The checkout asks for "a gateway for UPI"; the factory decides which class. */
    public static final class GatewayFactory {
        private final Map<String, PaymentGateway> byMethod;

        public GatewayFactory(Map<String, PaymentGateway> byMethod) {
            this.byMethod = byMethod;
        }

        public PaymentGateway forMethod(String method) {
            PaymentGateway g = byMethod.get(method);
            if (g == null) {
                throw new IllegalArgumentException("unsupported payment method " + method);
            }
            return g;
        }
    }
}

/**
 * [State] Each state knows which actions are legal and what comes next. Illegal transitions
 * (delivering a cancelled order) are impossible by construction.
 */
public enum OrderState {

    CONFIRMED {
        @Override
        public OrderState on(String action) {
            return switch (action) {
                case "pack" -> PACKED;
                case "cancel" -> CANCELLED;
                default -> reject(action);
            };
        }
    },
    PACKED {
        @Override
        public OrderState on(String action) {
            return switch (action) {
                case "dispatch" -> OUT_FOR_DELIVERY;
                case "cancel" -> CANCELLED;
                default -> reject(action);
            };
        }
    },
    OUT_FOR_DELIVERY {
        @Override
        public OrderState on(String action) {
            return switch (action) {
                case "deliver" -> DELIVERED;
                default -> reject(action); // too late to cancel: the rider is on the way
            };
        }
    },
    DELIVERED {
        @Override
        public OrderState on(String action) {
            return reject(action);
        }
    },
    CANCELLED {
        @Override
        public OrderState on(String action) {
            return reject(action);
        }
    };

    public abstract OrderState on(String action);

    OrderState reject(String action) {
        throw new IllegalStateException("cannot '" + action + "' an order that is " + this);
    }
}

/**
 * [Saga] (orchestration) for checkout: each step has a compensation; if a later step fails, the
 * completed steps are undone in reverse order. Every action is logged so the demo shows the flow.
 */
public final class CheckoutSaga {

    public record Step(String name, Runnable action, Runnable compensation) {
    }

    public static final class Failed extends RuntimeException {
        Failed(String message) {
            super(message);
        }
    }

    private final Consumer<String> log;

    public CheckoutSaga(Consumer<String> log) {
        this.log = log;
    }

    public void run(List<Step> steps) {
        Deque<Step> done = new ArrayDeque<>();
        for (Step step : steps) {
            try {
                step.action().run();
                log.accept(step.name() + " ✔");
                done.push(step);
            } catch (RuntimeException e) {
                log.accept(step.name() + " ✘ " + e.getMessage());
                while (!done.isEmpty()) {
                    Step undo = done.pop();
                    undo.compensation().run();
                    log.accept("compensate: undo " + undo.name());
                }
                throw new Failed(step.name() + " failed: " + e.getMessage());
            }
        }
    }
}

/**
 * Ordering's persistence (real H2 database). [Transactional Outbox]: every order change and the
 * event describing it are written in ONE transaction; {@link #relay} publishes them afterwards.
 * Checkout idempotency keys are a UNIQUE column, so a retried request can't create a second order.
 */
public final class OrderStore {

    public record OrderRow(String id, String customerId, Money total, OrderState state, String idempotencyKey) {
    }

    private static final AtomicInteger DB_COUNTER = new AtomicInteger();

    private final JdbcDataSource db = new JdbcDataSource();

    public OrderStore() {
        db.setURL("jdbc:h2:mem:freshcart_" + DB_COUNTER.incrementAndGet() + ";DB_CLOSE_DELAY=-1");
        exec("CREATE TABLE orders (id VARCHAR PRIMARY KEY, customer VARCHAR, total_paise BIGINT, state VARCHAR,"
                + " idempotency_key VARCHAR UNIQUE)");
        exec("CREATE TABLE outbox (seq BIGINT AUTO_INCREMENT PRIMARY KEY, event_id VARCHAR, type VARCHAR,"
                + " order_id VARCHAR, customer VARCHAR, total_paise BIGINT, state VARCHAR, published BOOLEAN DEFAULT FALSE)");
    }

    public void insert(OrderRow o, String eventId) {
        inTransaction(c -> {
            try (PreparedStatement ps = c.prepareStatement("INSERT INTO orders VALUES (?, ?, ?, ?, ?)")) {
                ps.setString(1, o.id());
                ps.setString(2, o.customerId());
                ps.setLong(3, o.total().paise());
                ps.setString(4, o.state().name());
                ps.setString(5, o.idempotencyKey());
                ps.executeUpdate();
            }
            outbox(c, eventId, "OrderPlaced", o.id(), o.customerId(), o.total().paise(), o.state().name());
        });
    }

    public void updateState(OrderRow o, OrderState next, String eventId) {
        inTransaction(c -> {
            try (PreparedStatement ps = c.prepareStatement("UPDATE orders SET state = ? WHERE id = ? AND state = ?")) {
                ps.setString(1, next.name());
                ps.setString(2, o.id());
                ps.setString(3, o.state().name()); // optimistic check: nobody changed it meanwhile
                if (ps.executeUpdate() != 1) {
                    throw new SQLException("concurrent update of " + o.id());
                }
            }
            outbox(c, eventId, "OrderStatusChanged", o.id(), o.customerId(), o.total().paise(), next.name());
        });
    }

    public Optional<OrderRow> byId(String id) {
        return query("SELECT * FROM orders WHERE id = ?", id);
    }

    public Optional<OrderRow> byIdempotencyKey(String key) {
        return query("SELECT * FROM orders WHERE idempotency_key = ?", key);
    }

    /** Publishes unpublished outbox rows in order (at-least-once) and marks them. */
    public int relay(DomainEvents events) {
        List<Event> pending = new ArrayList<>();
        List<Long> seqs = new ArrayList<>();
        try (Connection c = db.getConnection(); Statement s = c.createStatement();
             ResultSet rs = s.executeQuery("SELECT * FROM outbox WHERE published = FALSE ORDER BY seq")) {
            while (rs.next()) {
                seqs.add(rs.getLong("seq"));
                Money total = new Money(rs.getLong("total_paise"));
                pending.add(rs.getString("type").equals("OrderPlaced")
                        ? new OrderPlaced(rs.getString("event_id"), rs.getString("order_id"), rs.getString("customer"), total)
                        : new OrderStatusChanged(rs.getString("event_id"), rs.getString("order_id"), rs.getString("customer"),
                        rs.getString("state")));
            }
        } catch (SQLException e) {
            throw new IllegalStateException(e);
        }
        for (int i = 0; i < pending.size(); i++) {
            events.publish(pending.get(i));
            long seq = seqs.get(i);
            inTransaction(c -> {
                try (PreparedStatement ps = c.prepareStatement("UPDATE outbox SET published = TRUE WHERE seq = ?")) {
                    ps.setLong(1, seq);
                    ps.executeUpdate();
                }
            });
        }
        return pending.size();
    }

    /** Test hook: mark everything unpublished again, as if the relay crashed before marking. */
    public void simulateRelayCrashBeforeMarking() {
        exec("UPDATE outbox SET published = FALSE");
    }

    public long count(String table) {
        try (Connection c = db.getConnection(); Statement s = c.createStatement();
             ResultSet rs = s.executeQuery("SELECT COUNT(*) FROM " + table)) {
            rs.next();
            return rs.getLong(1);
        } catch (SQLException e) {
            throw new IllegalStateException(e);
        }
    }

    private void outbox(Connection c, String eventId, String type, String orderId, String customer, long total, String state)
            throws SQLException {
        try (PreparedStatement ps = c.prepareStatement(
                "INSERT INTO outbox (event_id, type, order_id, customer, total_paise, state) VALUES (?, ?, ?, ?, ?, ?)")) {
            ps.setString(1, eventId);
            ps.setString(2, type);
            ps.setString(3, orderId);
            ps.setString(4, customer);
            ps.setLong(5, total);
            ps.setString(6, state);
            ps.executeUpdate();
        }
    }

    private Optional<OrderRow> query(String sql, String param) {
        try (Connection c = db.getConnection(); PreparedStatement ps = c.prepareStatement(sql)) {
            ps.setString(1, param);
            try (ResultSet rs = ps.executeQuery()) {
                if (!rs.next()) {
                    return Optional.empty();
                }
                return Optional.of(new OrderRow(rs.getString("id"), rs.getString("customer"),
                        new Money(rs.getLong("total_paise")), OrderState.valueOf(rs.getString("state")),
                        rs.getString("idempotency_key")));
            }
        } catch (SQLException e) {
            throw new IllegalStateException(e);
        }
    }

    private interface TxWork {
        void run(Connection c) throws SQLException;
    }

    private void inTransaction(TxWork work) {
        try (Connection c = db.getConnection()) {
            c.setAutoCommit(false);
            try {
                work.run(c);
                c.commit();
            } catch (SQLException e) {
                c.rollback();
                throw new IllegalStateException(e.getMessage(), e);
            }
        } catch (SQLException e) {
            throw new IllegalStateException(e);
        }
    }

    private void exec(String sql) {
        try (Connection c = db.getConnection(); Statement s = c.createStatement()) {
            s.execute(sql);
        } catch (SQLException e) {
            throw new IllegalStateException(e);
        }
    }
}

/** [Rate Limiter] Token bucket per customer for checkout attempts (bots, double-taps, scripts). */
public final class TokenBucket {

    private final int capacity;
    private final double refillPerSecond;
    private final Clock clock;
    private final Map<String, double[]> buckets = new HashMap<>(); // key → {tokens, lastMillis}

    public TokenBucket(int capacity, double refillPerSecond, Clock clock) {
        this.capacity = capacity;
        this.refillPerSecond = refillPerSecond;
        this.clock = clock;
    }

    public synchronized boolean tryAcquire(String key) {
        long now = clock.millis();
        double[] b = buckets.computeIfAbsent(key, k -> new double[] {capacity, now});
        b[0] = Math.min(capacity, b[0] + (now - b[1]) / 1000.0 * refillPerSecond);
        b[1] = now;
        if (b[0] >= 1) {
            b[0] -= 1;
            return true;
        }
        return false;
    }
}

    What to notice:

    • (4) The low-stock alert fires inside the reservation step; it isn't critical, so it goes straight onto the in-process bus rather than through the outbox.
    • (6) The double tap returns 200 with the original order and makes zero calls to PayFast.
    • (8) The declined payment triggers compensations in reverse order; ghee stock is back to 40.
    • (9) After two timeouts the breaker opens; the third attempt fails fast without calling PayFast, and cash on delivery still works because it's a different gateway behind the same factory.
    • (10) Cancelling an order that's out for delivery is rejected by the state object; the status changes reach the customer as SMS via the outbox relay.
    • (12) After the relay "crashes", every event is delivered again: loyalty ignores both duplicate OrderPlaced events and no SMS is sent twice.

            }

    6. From this demo to production¶

    Demo Production
    Plain Java wiring in FreshCartDemo Spring Boot: modules as packages verified by Spring Modulith, beans wired in @Configuration
    DomainEvents in-process bus Spring ApplicationEventPublisher + @ApplicationModuleListener, then Kafka when modules are extracted
    H2 in memory PostgreSQL; outbox relay with FOR UPDATE SKIP LOCKED or Debezium

    If FreshCart grows to several teams, the modules are already the extraction plan: payment first (compliance, provider integrations), then catalog/search (read-heavy scaling), then delivery (separate team). Each extraction swaps an in-process call for an API and the in-process bus for Kafka, behind the same interfaces, following the strangler fig approach.

    7. Explain it in 5 minutes (interview script)¶

    "FreshCart is a modular monolith: catalog, cart, pricing, checkout, inventory, delivery, payment, ordering, notification and loyalty, behind a facade. Checkout is an orchestrated saga: reserve stock, book a delivery slot, charge payment (the pivot), then save the order. If payment fails, the saga releases the slot and the stock in reverse order. The order row and its OrderPlaced event are written in one transaction using the outbox; a relay publishes events to an in-process bus, which feeds SMS, loyalty points and a CQRS 'My orders' view. Every consumer is idempotent, so redelivered events are harmless, and checkout takes an idempotency key, so double taps don't double-charge. Payments go through a factory that returns an adapter for our provider wrapped in a circuit breaker, so an outage fails fast and customers can switch to COD. Orders follow a state machine; coupons are specifications with strategies; validations form a chain. A token bucket limits checkout attempts per customer. Each module has a small API, so the same design can be split into services later."

    8. Extend it yourself¶

    • Add a "Buy again" feature: a command that adds a previous order's items to the cart (and can be undone).
    • Add an ExpressDelivery slot strategy that picks the earliest slot for an extra ₹49, and price it in Pricing.
    • Add order cancellation with refund: cancel must also release stock, cancel the slot and refund via the original gateway, as a saga.
    • Persist loyalty's processed event IDs in H2 with a unique constraint, as in the Idempotent Consumer page.
    • Add ArchUnit rules (like the architecture tests) so loyalty can't depend on ordering.
    • Add distributed tracing: a trace ID created in checkout and carried in every event.
